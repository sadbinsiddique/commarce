# Components 

- Create REST Controllers
- Add dependency for Spring Data JPA
- Spring Boot Starter
- Spring Boot Actuator (good for monitoring)
- Spring Boot DevTools (good for development)
- Inject dependencies using @Autowired
- Use @RestController to create RESTful web services
- Use @RequestMapping to map HTTP requests to handler methods
- IOC (Inversion of Control) and DI (Dependency Injection) concepts
- Use @Component, @Service, @Repository to define beans
- Qualifier to resolve ambiguity when multiple beans of the same type exist
- Primary to indicate the primary bean when multiple beans of the same type exist
- Use @Value to inject values from properties files
- Use @Configuration to define configuration classes
- lazy initialization to improve startup time
